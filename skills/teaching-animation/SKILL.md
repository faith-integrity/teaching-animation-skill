# 教学动画制作

把教学意图变成可以逐镜头审核、局部修改和复现的动画。优先保证概念正确、画面易懂、字幕可读、声音完整，再增加装饰和转场。与操作者使用同一种语言沟通。

## 开始与接手

先阅读现有项目约束、当前规格、审核记录和最新交付清单，辨认当前生效版本。用户的新要求优先于旧文档；发现冲突时说明具体差异，更新当前规格，旧版本留在历史记录中。不要把旧“最终版”文件名当作最新版本的证据。

提取主题、受众、教学目标、来源材料、时长、画幅、声音要求和交付形式。信息不全时先写带假设的脚本草案；只问会改变知识解释、镜头结构、视觉身份或成本的关键问题。用户已说明的选择和审核结论不重复询问。

检查环境并完成最小渲染，见 [environment.md](references/environment.md)。已有可用环境优先复用；新项目默认考虑 Manim，用户指定其他引擎则沿用其选择。缺少模型、字体、依赖或调用工具时及时说明，并继续不依赖它们的工作，不能声称已生成实际未生成的媒体。

## 1. 脚本先行，明确审核边界

按 [planning.md](references/planning.md) 生成逐 Shot 脚本：每镜头的教学目的、初态、动作顺序、末态、字幕 C1/C2…、朗读文本、语义触发点、预计时长和验收点。C 是字幕 cue，不是新镜头，也不是 TTS 内部短句。保留稳定 ID。

先交付可读脚本供审核，按反馈迭代。操作者未批准脚本时，不把它升级为正式制作基线；可以生成帮助理解的低成本草图或明确标记的临时预演。若操作者明确要求“直接先做一版完整预览”，记录其已授权草案预演，提供全片低清初稿，不再要求逐镜头批准才能继续。预演不等于最终审核通过。

## 2. 视觉契约与低成本预览

与操作者确定通用对象的大小、形状、颜色、语义、层级、状态变化和允许的运动；确定标题文字、字体、字号、固定位置、字幕区域、行数、换行和公式排版。使用集中式样式常量和共享对象构造器。

输出一张同时包含代表性对象、最长字幕和复杂公式的样式板。遇到“更窄一些”“像图中这样”等影响较大的歧义，先给带编号的关键帧、前后对照或短预演；标明自己的理解和需要确认的差异。几何关系与时序不清时，不仅用文字追问。

已确认的手绘图、SVG、Visio 或课件保留为参考源，不覆盖人工编辑的原件。区分直接导出使用、按图重绘与可编辑对象导入，不能宣称三者完全等价。

## 3. 两种制作路径，允许切换

按用户选择推进；未指定时，选代表性镜头试制，再逐镜头或小组扩展。

- **全片优先**：生成低清全片，定位反馈至 Shot/Cue，单独精调并预览对应镜头，确认后合回全片。
- **逐镜头推进**：生成指定 Shot 的关键帧或动画，审核后处理下一镜头；相邻镜头有连续动作时生成联合审核版，最后装配全片。

两条路径都复用同一镜头实现、视觉规格和时间轴。分镜预览不得演化为与正式成片不同的副本。新设计或结构性修改先验证关键状态；纯文字或局部时序修改只验证受影响的范围，不机械重走所有阶段。

动画与公式实现见 [animation.md](references/animation.md)。技术实现和主观审核分开记录；脚本执行成功不能代替看画面和听声音。

## 4. 配音、参考音色、转写与同步

需要声音或转写时读取 [audio.md](references/audio.md)。支持现有 TTS/voice 服务、本地模型、操作者提供的录音及兼容模型的参考音色。先检查实际工具和模型能力，禁止虚构模型、音色 ID 或 API。先做包含专业术语、公式和长句的短试听，再批量生成。

屏幕 `display_text` 与实际 `speech_text` 分开保存，规范术语留在画面中；读音修正只作用于配音文本。TTS 片段可以多于字幕 cue，不擅自拆改已确认字幕。用实测声音时长、句内锚点和必要的画面停留生成统一时间轴；语音较长时延长稳定画面，不能截断尾句凑时长。

只重录需要修改的 cue/片段。模型和参考音色改变则重新评估缓存。转写保留原始识别文本、时间码、人工修订文本和不确定项，不把识别结果当作标准答案。参考音色的训练和推理分别处理，不因配音问题默认重训。

## 5. 及时澄清，具体交付审核

有会影响结果的歧义、材料冲突或缺失，立即指出影响哪个 Shot/Cue，展示当前理解、可选方案和推荐方案。只暂停依赖该决定的部分；不要用“等待审核”掩盖仍可完成的准备工作。

每次审核提供实际文件/预览、版本、变更范围、建议观看位置和一两个具体判断点。记录 `draft / review / approved / superseded` 与操作者实际确认的范围。不能从沉默、机器检查通过或部分镜头获批推断全片获批。

## 6. 局部修改、合并与交付

修改前确定生效基线及依赖：样式→哪些镜头；字幕→是否影响声音；声音→哪些时序；镜头→相邻衔接与全片。更新受影响资产，保留已通过内容。用源文件/参数/音频指纹判断缓存有效性，不能仅凭文件存在就复用。

依照 [delivery.md](references/delivery.md) 从**最终导出文件**检查每条 cue 的代表帧、关键动作、镜头交界、首尾音节、音视频流及完整解码。输出完整成片、需要的分镜审核版、源码、规格、时间轴和复现说明。封面、外部字幕和正文的时间偏移必须一起更新。

遇到吞字、噪声、长停顿、公式错位、对象残留或旧镜头回流，按 [troubleshooting.md](references/troubleshooting.md) 定位。两次相同失败后改变诊断方式或报告阻塞，不无休止重渲染/重配音。

## 工具与参考

- `scripts/doctor.py`：只读检查当前解释器、Manim、转写库、FFmpeg 和 TeX 工具；不自动安装。
- `scripts/transcribe.py`：用指定的本地 faster-whisper 模型转写，输出 JSON/TSV；不自动下载模型。
- `scripts/check_timeline.py`：检查实测 cue 时间轴及 WAV 时长；格式见 [timeline.md](references/timeline.md)。
- [project-template.md](assets/project-template.md)：新项目的脚本、视觉契约及审核记录模板，按需裁剪。
- [lessons.md](references/lessons.md)：六类教学动画经验的适用边界；不继承其中某门课程的视觉和物理数值。
