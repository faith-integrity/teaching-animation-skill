# 六类教学动画沉淀的经验

以下来自原制作过程的规格、交接、QA 和故障记录，已去除个人路径和素材；不是对六支最终视频的新一次完整审核。

| 来源主题 | 实际制作经验 | 通用化规则 |
|---|---|---|
| P/N 型半导体 | 晶格跨镜头保持；空穴接力曾需要修正双份电子；固定标题不能随转场闪烁 | 对象身份和父子层级明确，变化只作用于差异对象；连续状态保持不变量 |
| PN 结形成 | 长句缺尾、停顿累加；整数音频缩放不正确曾导致强噪声 | 原始模型输出与后处理分别检查；语义拆句；单一停顿预算和正确 PCM 转换 |
| PN 结单向导电 | 正偏到反偏需要回到基准状态；旧回路和粒子需要清理 | 教学状态切换有明确过渡，显式清理场景状态，不能让旧对象污染下一阶段 |
| BJT 放大原理 | 专业符号重复朗读；字母下标与中文公式混排需统一 | 朗读与显示分离；统一公式入口；区分变量下标和说明性下标 |
| JFET | 用户手改参考图；按显式 C 配音；单镜头定点重录再合并；相邻镜头共享主体 | 保留权威原件和 cue；局部改动追踪依赖；全片入口复用已审镜头 |
| NMOS | 语义短句回转录核查；动画动作要跟随具体句子；字幕修改可能需要重新配音 | ASR 辅助查漏字；句内事件锚点；修改影响声音、时间轴及交付时一起更新 |

不要继承为通用要求：白底、特定中文字体、固定字号、电子颜色、课程标题、0.19.1 版本、某个采样参数、某个 GPU、具体本机路径或个人音色。它们都属于项目配置。

静态画面确认不能保证运动正确，独立镜头确认不能保证合并正确，ASR 高相似度不能保证声音自然，旧高清版不能自动代表新脚本。把验证对象写清，比增加机械步骤更有效。
