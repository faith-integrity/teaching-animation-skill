# 动画实现与公式

## 可独立预览也可连续播放

让每个镜头拥有可重建的输入状态、输出状态和 `play_shot` 实现。关键帧与正式动画调用相同的对象构造器。单镜头包装器补充必要的入场/出场；全片入口可关闭这些包装效果并复用上一个镜头留下的对象。不要在全片入口复制一份旧镜头逻辑。

同一主体跨镜头连续存在时，不整页 clear 后重新淡入。只替换发生变化的对象；显式清理 updater、临时标记和粒子层，防止重复对象、旧箭头和残影。父子对象的增删要明确归属，不能既在父组中保留粒子又把副本加到 Scene。

共享电压、曲线点、器件边界或机械位置使用同一参数驱动，保持动作之间的因果关系。关键运动应检查开始、中途与结束，不能只看漂亮的末态。科学示意允许比例简化，但简化不应误导方向、数量守恒、拓扑和极限状态。

## 字幕、标题与公式

标题层、主体层、解释标注层和字幕层独立管理。标题固定时不参与主体转场。字幕按已确认 cue 切换，不由渲染器重新按标点拆分。

中文由支持中文的文本对象绘制；数学表达式走统一公式工厂。Manim 用 `Text` 与 `MathTex` 混排，完整等式尽量在单个 MathTex 中排版，避免手工拼接造成基线和间距错误。混排检查视觉基线，不仅对齐包围盒中心。

```python
MathTex(r"I_{\mathrm{C}}=\beta I_{\mathrm{B}}", font_size=30)
MathTex(r"x_i", font_size=30)  # i 是变量索引，保留斜体
```

物理变量主体、说明性下标、变量下标按领域规范分别处理。端子 GS/DS 等可以用白名单声明为正体，不对所有英文字母下标做全局正则替换。中文不直接塞入默认 LaTeX 模板；多字母下标、分数、负号、希腊字母及复杂不等式要单独验证。

公式太宽时先考虑按语义重排、换行或扩大合法区域；不能只缩小至无法辨认。保留用户确认的不等号、近似号和适用条件。符号样式改动后检查字幕和图内标签的最宽状态。

## 缓存与确定性

对象位置、粒子分配和必要随机性应可复现。改变外部 JSON、音频、SVG 或字体后确认渲染缓存依赖是否覆盖它们；怀疑旧缓存时只针对受影响渲染禁用缓存。关键数据修改后用最终文件抽帧验证，不能以源码已改为证据。
