# 根据症状定位

| 症状 | 先检查 | 修复与复验 |
|---|---|---|
| 句尾缺字、公式没读完 | 最终 speech_text、单条原始 WAV 与 ASR | 按语义拆片段，定点重录；试听结尾并核验否定词/条件 |
| 语速和音色突然变化 | 权重、参考片段、参数、后处理是否改变 | 固定 profile，重做问题片段；试听两侧接缝 |
| 强噪声、失真或削波 | 原始模型输出是否干净；PCM dtype/位深/缩放 | 修正转换，禁止放大近静音底噪；查峰值/RMS/削波并试听，先别重训 |
| C1 到 C2 空白过长 | 原始静音 + 拼接间隔 + cue 停顿 + 镜头淡出 | 合并停顿预算，只改受影响间隔；重新测时并播放交界 |
| 专业术语读错 | 原始朗读文本、模型支持的音素控制 | 建读音表或 cue 覆盖；同音字仅改 speech_text，不改标准字幕 |
| 声音已变、画面还是旧版 | manifest 指纹、主入口导入、缓存与交付路径 | 从正式入口重建受影响部分，从最终 MP4 抽帧及试听 |
| 曲线比解说提前变化 | 动作是否仅按整 cue 平均分配 | 用句内语义锚点触发，核验开始/中间/结束 |
| 公式下标歪斜或错位 | 普通 Text 伪公式、拆分 MathTex、字体回退 | 完整表达式统一工厂；说明性下标白名单；渲染最宽状态 |
| 对象闪现、复制、转场残影 | clear/rebuild、父子组、updater、透明叠层 | 复用共享对象，清理临时层；相邻镜头联合预览 |
| 单镜头正确、全片错误 | 全片是否调用不同函数、用了旧音频或重复包装转场 | 统一实现；显式选择版本清单，检查全片中对应位置 |
| 成片有声但尾句截断 | 使用 -shortest、视频比声音短、封面偏移 | 先修时间轴或延长稳定末态，完整解码并试听尾句 |
| 渲染失败 | 首个实际错误、依赖/字体/TeX、最小复现 | 缩小到单对象/单公式，不先重装所有依赖 |

将问题分类为内容、布局、运动、音频、同步或装配。每轮修复注明最小受影响范围及可观察验收点。相同失败出现两次，停止盲重试；检查中间资产或换最小复现。不会阻塞输出的升级提示不等同渲染失败。
