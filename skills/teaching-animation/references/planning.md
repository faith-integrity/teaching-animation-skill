# 脚本、视觉规格和审核

## 分镜设计

先列“学生看完应能解释什么”，再决定镜头数。一个镜头围绕一个主要教学目的；复杂因果关系用连续阶段表达，避免画面先暴露尚未讲解的结论。来源材料不足时标出待核实的概念，不替用户编造事实。

每个 Shot 写清：稳定 ID、目的、初态、动作及触发语句、末态、承接关系、字幕 cue、实际朗读文本、预计时长、关键帧和验收点。使用者称 K1/S1 时，记录别名映射，不擅自重编号。预计时长只是预算；配音后由实测时间轴替代。

每条 cue 用 `S03:C02` 之类的稳定键。长字幕按完整意思、自然停顿和画面阶段拆成 C1/C2/C3，避免在公式、固定术语、否定词与谓语之间截断。换行是同一 cue 的排版，不是新 cue。操作者已给定显式 cue 和换行时原样保留；超出布局时展示拆分或排版建议，经确认再改。

字幕模式需要说明：逐字解说、忠实改写，或提纲式字幕。不能默默省略用户要求的完整解说。公式读法可以口语化但不能漏掉条件、比较方向和近似限定。

## 审核状态

用轻量记录即可：对象 ID、版本、状态、实际反馈、确认范围、依赖版本。脚本、样式、试听、镜头和全片可以分别获批。用户说“这版可以，合回去”即足够授权合并，无需再问。用户仅说“看看这样如何”则属于探索。

脚本获批后改教学顺序或对象含义，说明受影响内容并请求针对变更的确认；字号微调等已授权修复不需要重新审批整份脚本。用户要求全片初稿时，展示假设后继续预演；其余正式制作依照已有审核范围推进。

## 视觉规格

使用一份可更新的现行规格，历史差异放日志，避免多段“优先级最高”的相互矛盾补丁。

| 类别 | 要确定的内容 |
|---|---|
| 画布 | 画幅、分辨率、帧率、背景、主体/字幕/标题安全区 |
| 通用对象 | 名称、含义、形状、尺寸单位、颜色值、描边、透明度、层级、锚点 |
| 对象变化 | 哪些状态可移动/替换/消失；不变量、数量关系及拓扑 |
| 文字 | 标题原文及是否全程固定；字体及回退、字号、字重、行距、最大宽高 |
| 公式 | 符号含义、上下标规范、完整表达式、单位、基线和读法 |
| 时间 | 语音前导、句内停顿、末态停留、镜头转场、封面偏移 |

不要把像素、Manim 场景单位和字号混用。字体不同必须重新检查实际边界框；不能用不断缩小字幕来掩盖信息过载。样式板至少覆盖最宽公式、最长两行/三行字幕、最密集图形和对象颜色含义。

## 自然语言与图示

先翻译成可观察要求，例如“更窄”具体是主体宽度减少还是空隙减少，“同步”是同时开始还是共用同一个进度。能从上下文推断的先给预览，不能确定且影响概念的才询问。示意图不清的部分单独标注；有用户手改文件时保护原件并记录校验值。静态预览验证布局，短动画验证运动，二者不能互相替代。
